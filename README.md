# Hebrew Bingo Generator

**[Try it live →](https://ybeapps.github.io/bingo/)**

A single-page web app for generating randomized Hebrew bingo cards, ready to print.

## Features

- Add words one at a time or as a comma-separated list
- 3×3, 4×4, and 5×5 grid sizes
- Optional free space in the center
- Generate up to 40 cards at once, each randomly shuffled
- Print layout: 2 cards per page, sized to fit A4/Letter in both Chrome and Safari

## Usage

Open `index.html` in any modern browser — no build step, no dependencies.

1. Type words into the input field (separate multiple words with commas)
2. Choose grid size and number of cards
3. Click **צור כרטיסי בינגו** to generate
4. Click **הדפס כרטיסים** to print
